# RadNet Anomaly Detection

[![Python 3.12](https://img.shields.io/badge/python-3.12-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)
[![Data: EPA RadNet + NOAA ISD](https://img.shields.io/badge/Data-EPA%20RadNet%20%2B%20NOAA%20ISD-orange.svg)](https://www.epa.gov/radnet)

**Methodology Note:** Features are strictly causal (zero forward lookahead, strict `NaN` propagation for missing weather telemetry, fit-fold `2017–2020` spectral basis estimation, validation-fold `2021–2022` threshold calibration, and held-out test `2023–2025` evaluation across 20 random seeds).

When it rains, natural radon daughters ($^{214}\text{Pb}$, $^{214}\text{Bi}$) wash out of the atmosphere onto EPA RadNet particulate filters. This produces sudden gamma count spikes of +40% to +180% that mimic radiological releases.

Conventional fixed and rolling $3\sigma$ thresholds fail under precipitation: across humid U.S. stations they trigger **53 to 83 false alarm episodes per station-year**, with up to 89% of alarm episodes in humid cities coinciding with rain.

This research project combines **8-channel EPA RadNet gamma spectrometry** with **NOAA ISD surface weather telemetry**, **causal radon spectral stripping**, and **Bateman progeny washout ODE dynamics** using LightGBM. Across a 20-seed evaluation, the full physics-informed nuclear and weather-fused model (`Tier 4: Physics-Informed Nuclear`) yields **2.71 ± 1.39 false alarm episodes per station-year** at the 95% validation target (**2.63 ± 1.49** at the 90% target; a **96.7% reduction** over rolling $3\sigma$) and **94.00 ± 0.93% detection of synthetic plumes** (with **91.10%** detected within $\le 12\text{ hours}$). These are simulation-benchmark results, not demonstrated detection rates for real releases.

## What is real and what is simulated

- **Real:** the EPA RadNet hourly gamma measurements and the NOAA hourly weather observations, 2017–2025, for five stations. The false-alarm counts are measured on this real, unmodified background.
- **Simulated:** the radiological "release" itself. No real release occurred at these stations in this period, so detection is measured on 450 synthetic plumes generated by this project's nuclear physics model (channel-resolved ICRP-74 ambient dose equivalent coupling and multi-nuclide Bateman filter accumulation/decay kinetics) and added on top of the real background. The ~94% detection figure applies to those synthetic plumes only; it is not evidence about real releases.
- **Not done yet:** validation on a real radiological event, and comparison with an operational alerting procedure. The baselines in the tables are simple statistical threshold rules written for this study.
- **Caveat on the 20 seeds:** all seeds use the same fixed set of 450 synthetic plumes, so the ± values reflect model randomness, not variation in release scenarios.

## How It Works

![Environmental Engineering Overview](reports/figures/environmental_engineering_synthesis.png)

1. **Continuous Air Monitoring**: EPA RadNet monitors draw ambient air through glass-fiber filters and record hourly gross counts (CPM), ambient dose rate (nSv/h), and 8 NaI(Tl) gamma energy channels (`R02`: 101–200 keV through `R09`: 1801–2200 keV).
2. **Environmental Confounders**:
   - **Precipitation Washout**: Rain scavenges airborne $^{214}\text{Pb}$ ($T_{1/2} = 26.8\text{ min}$) and $^{214}\text{Bi}$ ($T_{1/2} = 19.9\text{ min}$), causing immediate count surges (+40% to +180% at lag 0–1 h) that decay over 3–6 hours.
   - **Nocturnal Boundary-Layer Inversions**: Morning stability traps terrestrial radon progeny near the surface, creating a +5% to +15% daily oscillation peaking near 06:00–08:00 local time.
   - **Filter Tape Advances**: Automated filter replacements every 3–5 days cause abrupt step-drops of 340–720 CPM.
3. **Physics-Informed Nuclear & Meteorological Discrimination (`src/nuclear_physics.py` & `src/feature_engineering.py`)**:
   - **Channel-Resolved Energy-Weighted Dose Coupling**: Models $H^*(10)$ per count across `R02..R09` grounded in ICRP-74 conversion coefficients and NaI(Tl) intrinsic efficiency, anchored to empirical train-only radon washout regressions (`k_dose_channel`).
   - **Multi-Nuclide Bateman Filter Kinetics**: Simulates isotope-specific deposition and radioactive decay on the particulate filter for $^{131}\text{I}$ ($T_{1/2}=8.025\text{ d}$), $^{137}\text{Cs}$ ($30.17\text{ y}$), $^{134}\text{Cs}$ ($2.065\text{ y}$), $^{60}\text{Co}$ ($5.27\text{ y}$), and the coupled reactor pair $^{132}\text{Te} \to {}^{132}\text{I}$ ($76.9\text{ h} \to 2.295\text{ h}$).
   - **Causal Spectral Stripping & Bateman Washout ODE Residuals**: Projects dry-baseline-subtracted 8-channel excess vectors $\Delta \mathbf{C}(t)$ onto the fit-fold ($2017\text{--}2020$) station radon washout basis $\mathbf{s}_{\text{Rn}}$ (`radon_stripping_residual_l2`, `stripped_excess_r03_z`, `stripped_excess_r05_z`, `stripped_energy_weighted_dose_anomaly`) and solves the causal 3-stage $^{218}\text{Po}\to{}^{214}\text{Pb}\to{}^{214}\text{Bi}$ washout ODE driven by NOAA precipitation (`bateman_washout_residual_ratio`, `post_rain_persistence_anomaly`).

## Quickstart

### 1. Install Dependencies
Use Python 3.12 with the pinned dependencies. From the repository root:

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

macOS / Linux:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Activation is optional: on Windows, replace `python` below with `.\.venv\Scripts\python.exe`; on macOS/Linux use `.venv/bin/python`.

### 2. Verify the Code

The [test suite](tests) covers causal features, unknown weather, spectral conservation, Bateman kinetics, orthogonal radon spectral stripping, validation-only threshold selection, time gaps, CLI JSON, and pipeline failures. Lightweight checks use generated fixtures and the small result tables committed to Git. Integration tests use local station datasets and skip explicitly when they are absent.

```bash
python -m pytest -q -m "not integration"
# Also run dataset reconciliation and real model training; fail if data is missing:
python -m pytest -q --require-data
```

GitHub Actions runs the lightweight suite on Windows and Linux with Python 3.12.

### 3. Prepare Data and Run the Pipeline

Raw archives and compressed station datasets are intentionally excluded from Git. A fresh checkout has the code, small summary tables, and figures. Running the pipeline downloads the raw EPA/NOAA archives, merges and audits station time series, injects synthetic plumes, trains all model tiers, and generates all benchmark tables and figures:

```bash
python run_pipeline.py --dry-run
python run_pipeline.py --check
python run_pipeline.py
```

`--check` validates prerequisites, including outputs of preceding planned steps. It does not validate file contents or freshness. `--dry-run` prints all planned commands without executing them. Missing inputs, failed commands, and missing expected outputs cause a nonzero exit. Run the full workflow with `python run_pipeline.py`; `bash run_pipeline.sh` remains a compatibility wrapper.

### 4. Inspect Station Diagnostics

The [research CLI](src/detect_anomalies_cli.py) trains on 2017–2020, selects a 95% event-detection target on paired clean/injected 2021–2022 validation data, then freezes that threshold for inspection. Each invocation retrains and recalibrates. It never uses the mean threshold from the archived multi-seed table. An unreachable validation target is reported in the output.

```bash
python src/detect_anomalies_cli.py --station al_birmingham --start "2023-01-24 18:00:00" --end "2023-01-29 06:00:00"
python src/detect_anomalies_cli.py --station al_birmingham --tier tier4 --use-injected --start "2023-01-24 18:00:00" --end "2023-01-29 06:00:00" --json
```

Use `--threshold` for an explicit probability override, `--tier tier4` for the 59-feature Physics-Informed Nuclear model (`TIER_4_NUCLEAR_FEATURES`), and `--data-dir` for a different processed-data directory. Dates without an offset are UTC; offset-aware dates are converted to UTC. Paths default to the repository location, so the CLI also works from another directory. JSON errors return exit code 2; unknown values are `null`, never `NaN`. Missing weather coverage is reported per episode. Clean-background diagnostics have no ground-truth release labels.

## Research Limitations

- Detection is measured on synthetic injections. Natural washout labels are heuristic; clean-background alarms are not adjudicated real-world false positives.
- Classifier fitting uses 2017–2020 and threshold selection uses 2021–2022. While the channel dry baselines (`channel_mu_dry`, `channel_sigma_dry`) and radon washout basis vectors (`radon_washout_basis`) in `station_dry_baselines_train_only.json` are computed strictly on the 2017–2020 fit fold, the gross CPM dry normalizers (`mu`, `sigma`) use pre-test years 2017–2022.
- `hours_since_rain` and rainfall totals remain unknown until sufficient observed history exists. Retrain and recalibrate after changing feature semantics; old thresholds are not portable.
