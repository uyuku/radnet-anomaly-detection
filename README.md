# Weather-Aware Anomaly Detection in RadNet

EPA RadNet stationary gamma monitors (NaI(Tl) gross-count spectrometry) alarm on
every major rainstorm: scavenged radon progeny ($^{214}$Pb, $^{214}$Bi) wash out of
the air onto the filter and inflate the count rate by tens of percent. This project
quantifies that false-alarm burden on real 2017–2025 data from five U.S. stations and
tests whether fusing NOAA surface weather with multi-channel gamma spectrometry can
separate harmless radon washout from anthropogenic fission-product signals.

**Status:** Phases 0–5 complete with frozen results; Phase 6 (report) drafted in
`reports/PHASE6_REPORT.md`. Current maintainers: MiMo (lead developer),
Ömer (project lead).

## What is *not* in this repository (by design)

Per `PROJECT_SPEC.md` §2, raw downloads are read-only and gitignored:

- `data/raw/` — EPA RadNet annual CSVs and NOAA Global-Hourly files (re-download with
  `src/download_pilot_data.py` / `src/download_noaa_data.py`; see `DATA_LOG.md`)
- `data/processed/merged_{station}_2017_2025.csv.gz` — Phase 1 merged station panels
  (~324,550 synchronous hours; regenerated by `src/merge_radnet_weather.py`)
- `data/processed/labeled_{station}_{split}.csv.gz` — Phase 3 injected datasets
  (regenerated by `src/synthetic_injection.py`)

Consequence: in a clean checkout, the **plotting and audit scripts that read only
summary CSVs run as-is**; all upstream scripts need the re-downloaded raw data first.
`run_pipeline.sh` encodes exactly this behavior.

## Environment

Python ≥ 3.10. Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the pipeline

```bash
bash run_pipeline.sh              # full sequence
bash run_pipeline.sh --phase 5    # one phase
bash run_pipeline.sh --dry-run    # print commands only
```

Or phase by phase (see `HANDOFF.md` §3 for the script-by-script order):

```bash
python src/parse_stations.py            # Phase 0: station discovery
python src/download_pilot_data.py
python src/analyze_pilot_stations.py
python src/download_noaa_data.py        # Phase 1: NOAA weather
python src/audit_noaa_precipitation.py
python src/merge_radnet_weather.py
python src/plot_rain_events.py
# ... Phase 2 baseline, Phase 3 injections, Phase 4 models, Phase 5 rigorous eval
```

All scripts are run from the repository root. Seeds live in `configs/config.yaml`
(default `random_seed: 42`; the 20-seed Phase 5 replication uses seeds 42–61).

## Headline result (20-seed mean ± SD, 2023–2025 test split)

At matched ~92% detection of injected events, on unmodified background data:

| Detector | Clean false alarms / station-year |
| --- | --- |
| Rolling 7-day σ rule (k = 0.75, matched detection) | 303.11 |
| Gross CPM GBDT (Tier 1) | 168.62 ± 20.57 |
| Gross + weather GBDT (Tier 1b) | 68.21 ± 9.75 |
| Gross + spectral GBDT (Tier 2) | 8.52 ± 6.23 |
| **Gross + spectral + weather GBDT (Tier 3)** | **4.22 ± 1.29** |

Detection performance is measured **on synthetic injections** (no real fission-product
ground truth exists). Read `reports/PHASE6_REPORT.md` for the honest scope and
limitations.
